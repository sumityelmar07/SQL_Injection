What these numbers mean:
  • Precision: of all inputs the model flagged as injection, this fraction were actually injections. High precision = few false alarms.
  • Recall: of all actual injections in the test set, the model caught this fraction. High recall = few missed attacks.
  • F1: harmonic mean of precision and recall — a single number summarising both.
  • False-Positive Rate: fraction of legitimate inputs wrongly flagged as injection. Low FPR means fewer innocent users are blocked.
  • ROC-AUC: how well the model separates the two classes across all thresholds. 1.0 is perfect; 0.5 is random.
